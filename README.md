# AFRICASH

Plateforme d'affiliation francophone — structure prête pour une mise en production progressive.

Configuration demandée :
- Nom : AFRICASH
- Inscription : 2 500 FCFA
- Retrait minimum : 2 000 FCFA
- Retrait prévu : Mixx by Yas et Moov Money Flooz
- Affiliation + campagnes vidéo
- Base MySQL + backend PHP

IMPORTANT :
- Ce ZIP n'invente aucune API de paiement. Les paramètres Merchant ID, URL API, clés et signatures doivent venir officiellement du prestataire.
- Les récompenses vidéo doivent être financées par de vraies campagnes et validées côté serveur.
- Avant production : HTTPS, sessions sécurisées, password_hash/password_verify, CSRF, validation serveur, webhooks signés, anti-fraude, sauvegardes et journalisation.
- Les comptes marchands/paiements peuvent nécessiter un adulte responsable ou une structure légalement habilitée.
